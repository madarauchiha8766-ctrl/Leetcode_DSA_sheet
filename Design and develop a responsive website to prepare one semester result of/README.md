# 🎓 VIT Semester Result System (React + PHP + MySQL)

## 📌 Overview
This project calculates semester results using:
- React (Frontend)
- PHP (Backend)
- MySQL (Database)

---

## 🚀 Features
- Component-based React UI
- Props passing (Parent → Child)
- MSE (30%) + ESE (70%) calculation
- Backend DB connection

---

## 📂 Structure
frontend/
  App.js
  Student.js
  Result.js

backend/
  db.php
  SQL.txt

---

## 🧠 Concept Explanation

### React Components
- App → Parent
- Student → Child
- Result → Child

### Props
Data passed from App → Student → Result

### Formula
Total = (MSE × 0.3) + (ESE × 0.7)

---

## ▶️ How to Run

### Frontend
1. Create React app
2. Replace files
3. npm start

### Backend
1. Start XAMPP
2. Import SQL
3. Place PHP in htdocs
