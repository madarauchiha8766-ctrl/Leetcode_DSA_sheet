# 🔐 PHP Form Handling with Sessions and Cookies

## 📌 Project Overview
This project demonstrates:
- HTML form handling
- GET/POST methods
- Email validation
- Cookies
- Sessions

---

## 📂 Files
- index.html → Form
- process.php → Form processing
- dashboard.php → Session page

---

## ▶️ How to Run
1. Install XAMPP/WAMP
2. Place files in htdocs
3. Run via localhost

---

## 🧠 Explanation

### 1. Form Design
HTML form collects name, email, password.

---

### 2. POST Method
Data sent securely using POST.

---

### 3. Email Validation
PHP filter_var validates email format.

---

### 4. Cookies
Stores username for 1 hour.

---

### 5. Sessions
Stores user login state.

---

## 📌 Conclusion
This project explains basic authentication using PHP sessions and cookies.
