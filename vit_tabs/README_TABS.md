# 📊 VIT Learning Components Website (Tabs/Pills)

## 📌 Project Overview
This project is a dynamic website using Bootstrap tabs/pills to display:
- SDP (Skill Development Program)
- EDI (Entrepreneurship Development Initiative)
- DT (Design Thinking)
- Course Projects

---

## 🚀 Features
- Dynamic tabs using Bootstrap pills
- Responsive design
- Multi-column layout inside tabs
- jQuery animations
- Clean UI with cards

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- Bootstrap 4  
- jQuery  

---

## ▶️ How to Run
1. Open the file `vit_tabs.html`
2. Run it in browser

---

## 🧠 Detailed Explanation

### 1. Bootstrap Nav Pills
Used to create tab navigation:
- nav-pills class creates tab buttons
- data-toggle="pill" enables switching

---

### 2. Tab Content
Each tab content is defined using:
- tab-pane → container
- active → default visible tab
- fade → animation

---

### 3. jQuery Animation
Adds smooth fade effect when switching tabs.

---

### 4. Multi-Column Layout
Bootstrap grid system (row + col-md-6) creates columns inside tabs.
