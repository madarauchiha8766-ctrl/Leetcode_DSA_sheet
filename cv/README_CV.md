# 🎥 Responsive CV Website with Video Background

## 📌 Project Overview
This project is a responsive CV (Curriculum Vitae) website built using HTML, CSS, Bootstrap, and jQuery.  
It features a full-screen video background and a multi-column layout to display personal and professional information.

---

## 🚀 Features
- Full-screen video background
- Responsive design (mobile + desktop)
- Multi-column layout using Bootstrap grid
- Smooth scrolling navigation using jQuery
- Skills section with progress bars
- Projects and contact sections

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- Bootstrap 4  
- jQuery  

---

## ▶️ How to Run
1. Open the file `cv.html`
2. Run it in any browser

---

## 🧠 Detailed Explanation

### 1. Bootstrap Grid System
Bootstrap uses a 12-column layout:
- col-md-4 → takes 4 columns
- col-md-8 → takes 8 columns

This creates a responsive multi-column layout.

---

### 2. Video Background
A video element is used:
- autoplay → starts automatically
- muted → required for autoplay
- loop → repeats continuously

CSS ensures full-screen background using:
- position: fixed
- width/height: 100%

---

### 3. Overlay Effect
A dark overlay is added using rgba color:
This improves readability of text on video.

---

### 4. jQuery Smooth Scrolling
jQuery is used to animate scrolling when clicking navbar links.

---

### 5. Progress Bars
Bootstrap progress bars visually represent skills.

---

## 📌 Conclusion
This project demonstrates responsive design, UI enhancement using video backgrounds, and interactive navigation.
