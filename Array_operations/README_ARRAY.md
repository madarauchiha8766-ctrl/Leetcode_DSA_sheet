# 📊 JavaScript Array Operations Website

## 📌 Project Overview
This project demonstrates array operations using JavaScript:
- Reverse array
- Sorting array
- Searching element

---

## 🚀 Features
- Input array dynamically
- Reverse operation
- Sorting (ascending)
- Searching element
- Responsive UI using Bootstrap

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery

---

## ▶️ How to Run
1. Open array.html
2. Enter numbers separated by comma
3. Click buttons

---

## 🧠 Detailed Explanation

### 1. Input Handling
User enters numbers separated by comma.
We convert string into array using:
split(",") and map(Number)

---

### 2. Reverse Operation
Uses JavaScript reverse() function.
It reverses the order of array.

---

### 3. Sorting Operation
Uses sort() with compare function:
(a-b) for ascending order.

---

### 4. Searching Operation
Uses indexOf():
Returns index if found, else -1.

---

## 📌 Conclusion
This project demonstrates basic array operations using JavaScript and dynamic UI interaction.
